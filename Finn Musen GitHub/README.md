# Finn musen

Nettside der gjester markerer hvor et gjemt musehode henger, med admin for fasit, godkjenning og trekning.

- `site/` er nettsiden som publiseres (Vercel serverer denne mappen, se `vercel.json`).
- `apps-script/Code.gs` limes inn i Apps Script i et Google Regneark. Se `OPPSETT.md`.

Skriv aldri det ekte admin-passordet i `Code.gs` i dette repoet. Sett det bare i Apps Script-editoren.
